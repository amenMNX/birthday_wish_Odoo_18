# Module Anniversaires
🎂 Module Odoo - Gestion des Anniversaires (birthday_wish_18)
Un module Odoo Enterprise complet pour gérer, célébrer et automatiser les anniversaires des employés.

✨ Fonctionnalités Principales
📅 Tableau de bord intelligent : Vue des anniversaires du jour, de la semaine et du mois.

🤖 Notifications automatiques : Envoi d'emails et de vœux d'anniversaire.

📊 Rapports avancés : Statistiques par département, mois et statut de célébration.

💼 Gestion des célébrations : Suivi des cadeaux, budget et notes.

🌐 Interface Web : Pages accessibles via /birthdays/today et autres URLs.

🏗 Structure du Module

🚀 Installation
Copier le module dans le dossier addons d'Odoo

Redémarrer le serveur Odoo

Activer le mode développeur dans Odoo

Installer le module "birthday_wish_18" depuis les Applications
